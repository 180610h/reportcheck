# レポート添削ペン

大学のレポートを提出前に採点・添削するチャット型のWebアプリ（PWA）です。

## 使い方
1. レポートを入力欄に貼り付けるか、ファイルを添付する（ドラッグ＆ドロップ・画像の貼り付けも可）
2. 課題の条件（水準・分野・目標文字数・課題文）を合わせて「採点する」を押す
3. 採点結果が一覧表とコメントで返ってくる。そのあと「質問する」で相談できる

## 読み込める形式
- **PDF**（スキャンを含む）・**画像**（印刷物や手書きの写真）…AIが紙面をそのまま読む
- **Word（.docx）**・**ODT**・**テキスト** …本文と脚注を取り出してAIに渡す（画面には表示しない）
- 旧形式の .doc と Pages は、.docx か PDF に書き出してから使う

## 採点結果
- 総合点・評定（S〜D）・文字数・AI生成らしさ（%）
- 観点別の評価（問い・論証・分析・考察・具体性・出典・構成・表現）：点数・コメント・改善のポイントの一覧表
- 形式チェック（文字数・文体・話し言葉・文の長さ・誤字・出典・段落・見出し）の一覧表
- 優先して直す点、良い点、考察を深める問い、先生からのコメント
- 同じファイルを再提出すると前回比を表示。「採点の記録」で任意の2回を比較、バックアップの書き出しも可能

## AIの接続
- **APIキー方式**：「AI設定」に Anthropic の APIキーを入力（キーは端末のブラウザにだけ保存）
- **中継サーバー方式**（大学で配布する場合）：`worker/proxy.js` を Cloudflare Workers に置き、キーをサーバー側で管理

採点・質問のたびに、ファイルや本文が Anthropic の API に送信されます。

## 注意
AI生成らしさの数値は推定で、AIを使った証拠にはなりません。成績評価や不正の判断をこの数値だけで行わないでください。
