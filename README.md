# レポート添削ペン

大学のレポートを提出前にチェックするWebアプリ（PWA）です。

## 端末内で動くチェック（AI不要・オフライン可）
- **形式チェック**：文体の混在、話し言葉、決まり文句、曖昧表現、長文、表記
- **提出前チェックリスト**：文字数、文体、出典（本文中の引用と参考文献リスト）、自分の主張、構成
- **深さ分析**：具体性・根拠・分析・多角性・考察・自分の主張を0〜100で目安化
- **AI生成らしさ（文体統計）**：文長のばらつき、決まり文句の密度、文末の単調さなど7つの特徴から推定し、内訳も表示

## レポート専用AI（Claude）
- **AI評価**：問い・論証・分析・考察・具体性・出典・構成・表現の8観点を5段階で採点。本文を引用しながら優先して直す点、考察を深める問い、AI生成らしさ（%）と根拠を返す
- **AIに相談**：レポートについて質問できるチャット。代筆はせず、自分で直せるように導く方針

AI機能を使うときだけ、本文と課題文が Anthropic の API に送信されます。

### 接続方法
1. **APIキー方式**：アプリの「AI設定」に Anthropic の APIキーを入力（キーは端末のブラウザにだけ保存）
2. **中継サーバー方式**（大学などで配布する場合）：`worker/proxy.js` を Cloudflare Workers に置き、APIキーをサーバー側で管理。利用者は Worker のURL（と任意のアクセスコード）を入力するだけで使える

## 注意
AI生成らしさの数値は推定で、AIを使った証拠にはなりません。成績評価や不正の判断をこの数値だけで行わないでください。
