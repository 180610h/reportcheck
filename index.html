AI生成らしさの判定

文体統計の内訳

AI生成らしさは文章の特徴からの推定で、確率の目安です。定型的な書き方の人の文章も高く出ることがあり、AIを使った証拠にはなりません。教員が判定に使う場合も、この数値だけで判断しないでください。

1000字あたりの手がかり語・数値・引用の量から、内容の深さを0〜100で目安化しています。語の有無で測るため、内容の正しさは評価しません。正確な評価は「AI評価」を使ってください。

直すべき直した方がよい見直し候補AIの指摘

「AIで評価する」を押すと、レポート専用AIが8つの観点（問い・論証・分析・考察・具体性・出典・構成・表現）で採点し、優先して直すべき点とAI生成らしさを返します。本文はAnthropic社のAPIに送信されます。

このレポートについて、添削AIに相談できます。代筆はせず、自分で直せるように導く方針です。

形式チェック・深さ分析・文体統計の判定は、この端末の中だけで計算します。「AI評価」「AIに相談」を使ったときだけ、本文と課題文が Anthropic 社の API に送信されます。

自動チェックは目安です。「AIっぽい言い回し」は禁止語ではなく、多いと中身の薄い文章に見えやすい表現の一覧です。最終判断は自分の目で。
