# AI社員の使い方（毎週の流れ）

## 最初の準備（1回だけ）

使っているAI（Claude、ChatGPTなど）で、AI社員を2人作ります。

| AI社員 | 作り方 | 指示欄に貼るもの |
|---|---|---|
| 分析担当 | Claudeなら「プロジェクト」、ChatGPTなら「GPTs」や「プロジェクト」を新しく作る | [01_分析担当.md](./01_分析担当.md) の線から下 |
| 企画担当 | 同じように、もう1つ作る | [02_企画担当.md](./02_企画担当.md) の線から下 |

分析担当と企画担当は**別々に作る**のがおすすめです。
役割を分けたほうが、それぞれの出力がぶれにくくなります。

## 毎週の流れ（20分ほど）

```
① スプレッドシート → ② 分析担当 → ③ シートに追記 → ④ 企画担当 → ⑤ 撮影・投稿
```

### ① データを用意する（2分）
スプレッドシートのメニュー「Instagram分析」→「分析担当AIに渡すデータを作る」→「すべてコピー」

### ② 分析担当に渡す（5分）
新しいチャットを開いて、次のように送ります。

```
今週の分析をお願いします。

（ここにコピーしたデータを貼り付け）
```

月初めは「今週の分析」を「先月の月次の振り返り」に変えて送ります。

### ③ 伸びたタイトル集に追記する（1分）
分析レポートの「7. 伸びたタイトル集に追記する行」をコピーし、スプレッドシートの「伸びたタイトル集」シートの空いている行のA列に貼り付けます。

タブ区切りになっているので、列ごとに分かれて入ります。

### ④ 企画担当に渡す（5分）
新しいチャットを開いて、次のように送ります。

```
今週のリール企画を5本お願いします。

【分析担当からの引き継ぎ】
（分析レポートの「8. 企画担当への引き継ぎ」を貼り付け）

【はるからの希望】
（例：今週は3本だけ／LINE画面を見せる企画を入れたい／顔出しなし など。なければ「特になし」）
```

### ⑤ 撮影・投稿して、シートに記録する
投稿したら、スプレッドシートの「投稿データ」に冒頭テロップ・型・悩みテーマなどを入れます（1本1分）。
企画書に書いた型・悩みテーマをそのまま選べばOKです。

## うまく回すコツ

- **相談のときは「どの動画を見て来ましたか？」と必ず聞く**：「相談につながったタイトル」が分かるようになり、分析の質が一番上がります。
- **最初の1か月は「仮説を試す期間」と考える**：投稿が30件くらいたまるまでは、AIの分析も「仮説」が中心になります。外れても大丈夫です。
- **AIの出力はそのまま使わず、はるの言葉に直す**：台本は、はるが普段話す言い方に変えてから撮ると、「本人の経験からくる共感」というブランドの強みが出ます。
