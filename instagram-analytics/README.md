# 恋愛の家庭教師｜Instagram分析シート

Instagramの数字を毎朝自動でGoogleスプレッドシートに記録する仕組みです。
分析担当AIは、このシートを読んでレポートを作ります。

```
Instagram（公式API）→ Google Apps Script（毎朝6時に自動実行）→ スプレッドシート → 分析担当AI → 企画担当AI
```

---

## できあがるシート

見出しの色で、誰が書く列かが分かるようになっています。

- 🟦 **青**：自動で入る列
- 🟨 **黄**：手で入力する列（スクリプトは上書きしません）
- 🟩 **緑**：自動で計算される列

| シート | 中身 | 手で入れるもの |
|---|---|---|
| 投稿データ | 投稿ごとの再生数・リーチ・保存・シェア・平均視聴秒数など | 冒頭テロップ、カバー文字、型、悩みテーマ、自分ごと感、感情、ブランドNG表現、3秒維持率 |
| アカウント日次 | 毎日のフォロワー数・リーチ・再生数など | なし |
| 導線（週次） | 週ごとのリーチ → LP → 診断 → LINE → 相談の流れと通過率 | LP閲覧数、LINE追加数（経路別） |
| 相談記録 | 無料LINE相談の記録（件数は「導線」と「投稿データ」に自動で反映） | すべて手入力 |
| コメント | 投稿についたコメントの本文（自分の返信は除く） | 悩みテーマ、タイトルに使えそうな言葉 |
| 伸びたタイトル集 | 分析担当AIが「伸びた」と判断したタイトルを積み上げる | 分析レポートの追記行を貼り付け |
| AI用データ | 「分析担当AIに渡すデータを作る」で作られる、AIに貼るための文章 | なし |
| フォロワー属性 | 性別・年齢の割合（週1回更新。フォロワー100人以上で取得できます） | なし |
| 選択肢 | 「型」「悩みテーマ」などのプルダウンの中身（自由に変更できます） | 必要に応じて |
| ログ | 自動実行の結果とエラー | なし |

## セットアップ手順（初回だけ・合計1時間ほど）

### ステップ1：Metaでアクセストークンを発行する（30〜40分）

Metaの画面は時々変わるため、ボタン名が少し違うことがあります。

1. https://developers.facebook.com/ にFacebookアカウントでログインし、開発者として登録する
2. 「マイアプリ」→「アプリを作成」
3. ユースケースで **「Instagramでメッセージとコンテンツを管理」**（英語表示なら *Manage messaging & content on Instagram*）を選ぶ
   - ビジネスポートフォリオは「今はリンクしない」で大丈夫です
4. アプリができたら、左のメニューから「ユースケース」→ Instagram の「カスタマイズ」→ **「Instagramログインによる API 設定」** を開く
5. 「権限」に次の3つが入っていることを確認する
   - `instagram_business_basic`
   - `instagram_business_manage_insights`（数字の取得）
   - `instagram_business_manage_comments`（コメントの取得）
6. 「アクセストークンを生成する」の欄で **「アカウントを追加」** → 恋愛の家庭教師のInstagramでログインして許可する
   - 「テスターの招待を承認してください」と出た場合は、Instagram（ブラウザ版）の 設定 →「アプリとウェブサイト」→「テスターへの招待」から承認します
7. 追加したアカウントの横の **「トークンを生成」** を押し、表示されたトークンをコピーする

ポイント：

- アプリは「開発モード」のままで大丈夫です。自分のアカウントのデータを取るだけなら審査はいりません。
- トークンは60日で期限が切れますが、このシートが毎週自動で延長します。
- トークンはパスワードと同じです。チャットやSNSに貼らないでください。

### ステップ2：スプレッドシートにスクリプトを入れる（10分）

1. Googleスプレッドシートを新しく作る（名前の例：「恋愛の家庭教師 Instagram分析」）
2. メニューの「拡張機能」→「Apps Script」を開く
3. 最初から入っている `function myFunction() {...}` を消して、[`Code.gs`](./Code.gs) の中身を全部貼り付けて保存する（💾）
4. スプレッドシートのタブに戻って、ページを再読み込みする
5. 上のメニューに **「Instagram分析」** が出てくる

### ステップ3：メニューを上から順に押す（10分）

| 順番 | メニュー | やること |
|---|---|---|
| ① | 初期設定（シートを作る） | 初回は「承認が必要です」と出るので、自分のGoogleアカウントを選んで許可します（「このアプリはGoogleで確認されていません」と出たら「詳細」→「〜（安全ではないページ）に移動」→「許可」） |
| ② | アクセストークンを登録 | ステップ1でコピーしたトークンを貼り付けます。「接続できました！ @アカウント名」と出ればOK |
| ③ | 今すぐデータを取得 | 過去の投稿（19件）がまとめて入ります |
| ④ | 過去28日分の日次データを取り込む | 導線シートの過去分が埋まります |
| ⑤ | 毎日の自動取得をオンにする | 以後は毎朝6時に自動更新されます |
| — | 分析担当AIに渡すデータを作る | 毎週の分析のときに使います（[AI社員の使い方](./prompts/00_使い方.md)） |
| — | 診断フォーム（Googleフォーム）を連携 | 診断フォームの**編集画面のURL**を貼ると、毎週の回答数が自動で入ります |

## 自動で取れないもの（手で入れる・別の画面で見る）

| 項目 | どこで見るか | どこに入れるか |
|---|---|---|
| 冒頭テロップ・カバー文字 | 自分の投稿 | 投稿データ |
| 3秒維持率 | Instagramアプリ → 投稿のインサイト | 投稿データ |
| LP閲覧数 | Googleアナリティクス（下記） | 導線（週次） |
| LINE追加数（経路別） | LINE公式アカウントの管理画面 →「分析」→「流入経路分析」 | 導線（週次） |
| 相談の記録 | 相談のときにメモ | 相談記録 |

### LINE追加を「LP経由」と「診断経由」に分ける方法

LINE公式アカウントの管理画面で、**友だち追加用のURLを2つ**作ります（流入経路分析の機能を使います）。
LPのボタンには1つ目、診断結果ページのボタンには2つ目のURLを入れると、経路別の人数が見られるようになります。

### LPの閲覧数を測る方法

LPにGoogleアナリティクス（GA4）のタグを入れておくと、週ごとの閲覧数が分かります。
LPのHTMLにタグを入れる作業はClaudeに頼めます。

### 相談のときに必ず聞くこと

> 「ちなみに、どの動画を見て相談しようと思いましたか？」

答えてもらった投稿のURLを「相談記録」の「見た動画」に貼ると、「投稿データ」の **「相談につながった数」** に自動で数が入ります。
これが「伸びたタイトル」と「相談につながるタイトル」を分けて考えるための一番大事なデータです。

相談記録には、名前やLINEの表示名など**個人が分かる情報は書かないでください**。

## 手入力の目安（週15分ほど）

- **投稿したとき（1分）**：冒頭テロップ、型、悩みテーマ、自分ごと感、感情を選ぶ
- **投稿の2〜3日後（1分）**：アプリで3秒維持率を見て入力する
- **相談したとき（3分）**：相談記録に1行書く
- **週1回（5分）**：LP閲覧数とLINE追加数（経路別）を導線シートに入れる

## うまくいかないとき

- **「ログ」シートを見る**：エラーの内容が記録されています。
- **「アクセストークンの延長に失敗」と出る**：トークンの期限が切れています。ステップ1の7でトークンを作り直し、メニューの「② アクセストークンを登録」で入れ直してください。
- **「取得できなかった指標」と出る**：Instagram側がAPIで出していない数字です（リールのプロフィールアクセスなど）。エラーではないので、そのままで大丈夫です。必要なものはアプリで見てメモ欄に入れてください。
- **スクリプトを新しい版に貼り替えたとき**：メニューの「① 初期設定」をもう一度押してください。足りないシートや列だけが追加され、入力済みのデータはそのまま残ります。
- **フォロワー属性が空**：フォロワーが100人未満だと取得できません。
- **APIのバージョン**：`Code.gs` の最初にある `API_VERSION`（現在 `v23.0`）で決まっています。Metaがバージョンを終了したときは、ここを新しい番号に変えてください。
